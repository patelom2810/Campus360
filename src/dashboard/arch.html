Core Transformation Rules Applied Across Ingestion:

  • Identifier Standardization: Converted all arbitrary column names (mixed CamelCase, PascalCase, whitespace, symbols) to uniform lowercase snake_case identifiers via regex.

1. Anchor Selection Rationale

The Shambhuraje dataset was selected as the master anchor (25,000 students) because it provides an unbroken, 100% complete population baseline covering core demographics (branch, gender, state, tier), multi-term academic behaviors, 44 detailed skill attributes, and verified placement outcomes. Anchor records were assigned immutable synthetic IDs: STU00001 through STU25000.

2. Tertile & Demographic Matching Methodology

Because independent institutional datasets lack a shared universal identifier (such as an SSN or national roll number), the stitching engine executes attribute-based similarity matching without replacement. The anchor cohort and secondary tables are partitioned into performance tertiles (Low, Medium, High) using continuous distribution quantiles (pd.qcut(..., q=3)). Within each performance band, records are joined on overlapping demographic attributes (gender and engineering branch clusters: Tech vs. Core Engineering). Matched records are sampled randomly without replacement, ensuring every secondary row joins to at most one anchor student and preserves genuine behavioral correlations.

Stitching-Induced Correlation Confound (The Suvidya Ceiling Test Finding)

During evaluation of an external risk proxy (suvidya_pass_fail on 5,000 matched students), testing an academic-enhanced model (Model B) against a lifestyle-only model (Model A) showed an apparent dramatic leap in ROC AUC from 0.6065 to 0.8728 (Δ = +0.2663).

Honest Methodological Finding: Feature importance analysis revealed that 59.32% of Model B's predictive power was driven exclusively by anchor_cgpa. Because anchor CGPA tertiles were used as the primary similarity key during data stitching, secondary academic features inherit an artificially amplified synthetic relationship with the anchor target. This finding is transparently disclosed to ensure reviewers understand that synthetic attribute alignment can introduce subtle confounding into downstream ML models.

1. Ground-Truth Target Label Formulation

To overcome severe target imbalance in raw placement status (98.4% placed), an operational composite academic risk label was formulated across all 25,000 students:

at_risk_flag = 1 if (anchor_backlog_history ≥ 1 OR anchor_attendance_percentage < 55 OR anchor_cgpa < 5.5) else 0

Resulting Population Balance: 68.1% Safe (17,025 students) / 31.9% At-Risk (7,975 students). On the 5,000 held-out test split: 3,405 Safe / 1,595 At-Risk.

Strict Label Leakage Elimination: Why 3 Features Were Explicitly Excluded

When an ML model predicts at_risk_flag while including anchor_backlog_history, anchor_attendance_percentage, or anchor_cgpa, its test accuracy trivially exceeds 99%. However, this is mathematical circularity (target leakage) — the model is merely discovering the definition of the label rather than discovering early predictive signals.

EXCLUDED COLUMNS (LEAKAGE):
anchor_backlog_history anchor_attendance_percentage anchor_cgpa
INCLUDED MATRIX (23 FEATURES): Exclusively Lifestyle, Study Hours, Motivation, Wellness & Skills.

2. Normalization & Peer Benchmarking Mechanics

  • Population Normalization: Each component value is normalized against the full 25,000 student population minimum and maximum: norm = (raw - min) / (max - min) * 100.0, clipped safely to [0.0, 100.0]. (Projects combines anchor_development_projects_count + anchor_ai_ml_projects).
  • Branch & Tier Peer Subgroup: Students are benchmarked against peers enrolled in their exact same branch and college tier (e.g., Computer Science · Tier 2).
  • Skill Gap Ranking: The student's empirical percentile rank within their branch is calculated for each of the 6 components. The lowest percentile component is surfaced as the Suggested Focus Area with rule-based recommendations.
  • Progressive Band-Widening Fallback for Placement Reference: To query historical placement rate and average salary for peers with similar readiness scores, the engine searches within progressive score bands: ±10 pts → ±15 pts → ±20 pts requiring a minimum sample size of N ≥ 30 peers. If still under 30, it falls back to the coarse branch+tier subgroup; if still under 30, it flags insufficient_peer_data: true to avoid publishing unreliable small-sample stats.

Consolidated Known Limitations Index

Every engineering and machine learning limitation mapped directly back to its originating pipeline layer.

1. Model 1 Weak Explanatory Power (R² = 0.2096)
Originates in: Layer 5 (Model 1 Regression)

Continuous grade prediction based on habits and skill scores captures ~21% of variance. It provides directional sensitivity rather than exact grade forecasts.

2. Model 2 Early-Stage Screening Recall (45.14%)
Originates in: Layer 6 (Model 2 At-Risk)

Academic metrics were eliminated to prevent circular target leakage. Lifestyle variables alone provide weak predictive power (AUC = 0.5044), so ~2 in 3 flags are false alarms.

3. Stitching-Induced Confound (Suvidya Ceiling)
Originates in: Layer 3 (Data Stitching)

Adding academic telemetry lifted Suvidya pass/fail AUC from 0.6065 to 0.8728, but 59.32% of importance came from anchor CGPA, which was the stitching similarity key.

4. Secondary Cohort Match Sparsity
Originates in: Layer 3 (Coverage Table)

Secondary datasets cover sub-cohorts (Navin 4%, Sehaj 8%, Suvidya 20%, Sakhare 48%, Kundan 60%). Core ML models rely strictly on 100% complete anchor attributes.

5. Career Readiness Model is Rule-Based Heuristic
Originates in: Layer 7 (Career Engine)

Career Readiness Scoring (0–100) and percentile gap rankings are computed via calibrated domain weights, not an autonomous ML model (training script is an intentional stub).

6. GenAI External Network Dependency
Originates in: Layer 8 (GenAI Synthesis)

External API calls can experience upstream latency or transient outages. Campus360 handles this via in-memory caching and deterministic template fallbacks.
